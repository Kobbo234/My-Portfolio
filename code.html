Science Fair projects 2024

Automatic smoke detection system

Detect smoke particle using smoke detection sensor and sending infomation into
line application The system is a box with various sensor inside
The system component include :

  • MQ-3 smoke detection sensor
  • DHT-11 Temperature sensor
  • Esp32 Microcontroller
  • 8mm LED light Bulb
  • Passive buzzer

The system can notify user by using Linenotify.api which can alert user by sending messages through line appication (Note : Linenotify.api is discontinue by line since 2025)
This project got 3rd place at the Scince fair for good invention.
